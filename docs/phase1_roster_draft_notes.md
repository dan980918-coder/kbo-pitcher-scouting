# 2014~2025 KBO 신규 외국인 투수 명단 — 방법론 및 검증 이력

## 상태: STATIZ 전수 검증 완료 (2026-08-15)

**최종 167명, 전원 STATIZ 원문으로 개별 대조 완료 (verified_statiz=1, 167/167 = 100%).**
STATIZ 기준 연도/팀 불일치(순수 오탐)는 0건이었지만, 검증 과정에서 v1(위키 기반)의 실제 오류 다수를 발견해 정정·제외했다. 아래에 전체 이력을 정리한다.

## 방법론 확정 사항 (PROJECT_GUIDELINES.md에 반영 완료)

1. **"KBO 첫 시즌"의 기준**: 계약/신인지명 시점이 아니라 **실제 1군 출전 기록이 있는 시즌**. STATIZ가 "신인지명"(계약 시점)과 "활약연도"(실전 기록)를 다르게 표기하는 경우가 실제로 있었다(예: 앤드루 시스코 — 신인지명 2014년 kt, 실전 기록은 2015년뿐 → 그의 KBO 첫 시즌은 **2015년**으로 확정).
2. **`kbo_no_appearance` 플래그**: 계약은 했지만 정규시즌 0경기인 선수는 모집단에서 빼지 않되, WAR을 0이 아니라 **결측**으로 처리한다. STATIZ는 이런 선수의 개인 페이지 자체를 만들지 않는 것으로 확인됐다(에니 로메로, 파커 마켈 — 둘 다 검색해도 페이지가 없거나 경기 기록이 전혀 없음). 메인 WAR 회귀 타깃에서는 제외하고 "가용성 실패" 사례로 별도 집계한다. **현재 2건**: 에니 로메로(2023 SSG), 파커 마켈(2017 롯데).

## v1(171건) → v2(167건) 정정·제외 이력

### 팀 소속 오류 정정 (2건)
- **테일러 와이드너 (2023)**: v1은 "삼성/NC 충돌"로 미해결 보류. STATIZ 확인 결과 신인지명은 NC(1/31 계약), 2023-08-10 NC→삼성 트레이드. **NC로 확정**, 삼성은 시즌 중 이적처일 뿐.
- **시라카와 케이쇼 (2024)**: v1은 "두산/SSG 충돌"로 미해결 보류. STATIZ 확인 결과 신인지명은 SSG(부상 대체), 2024-07-10 SSG→두산 트레이드. **SSG로 확정**, 두산 표기는 리서치 에이전트의 오류였다.
- **브록 다익손 (2019)**: v1은 "롯데"로 기재. STATIZ 확인 결과 원래 SK가 신인지명(2019-06-10 SK→롯데 트레이드). **SK로 정정**.

### 연도 오류로 명단에서 제거 → 2026 트랙으로 이동 (3건)
- **오스틴 보스**: v1은 "2025 삼성"이었으나 STATIZ 활약연도가 2026년뿐. 2026 신인지명 확인.
- **크리스 페덱**: 오스틴 보스와 동일 사유, 신인지명 2026 삼성.
- **미야모리 사토시**: v1은 "2025 삼성"이었으나 STATIZ 신인지명이 **"26 삼성 아시아쿼터"**. 연도뿐 아니라 신분(일반 자유선발이 아닌 아시아쿼터)도 달랐다. PROJECT_GUIDELINES.md에서 이미 "2026 아시아쿼터는 별도 검토" 원칙을 세워뒀는데, 정확히 그 사례였다.

### 투수가 아니어서 완전히 제외 (1건)
- **타일러 화이트 (2020, SK)**: v1은 "닉 킹엄의 부상 대체 투수"로 분류했으나, STATIZ 확인 결과 이 선수는 **포지션이 1B(내야수)**로 등록되어 있고 투구 기록이 전혀 없다(9경기 타율 .136의 타자 기록만 존재). 애초에 투수가 아니었다.

### 이름·속성 정정 (2건)
- **"닉 에디튼" → "닉 애디튼"**: 위키 표기 오기. 정확한 이름은 Nick Additon. 파커 마켈의 대체 영입 선수(3/29 입단)였음을 뉴스로 확인, 대체영입여부를 N→Y로 정정.
- **브랜던 워델 대체영입여부**: v1은 N이었으나, 뉴스 확인 결과 2022-07-13 아리엘 미란다 부상 대체 영입이었다. Y로 정정.

### 실전출전여부 정정 (1건, 0경기 확정)
- **파커 마켈 (2017 롯데)**: STATIZ에 신인지명 기록은 있으나 주요기록 표에 경기 기록이 전혀 없음("조회된 데이터가 없습니다"). 실전출전여부 Y→N, `kbo_no_appearance=1`로 정정.

### 재영입 제외 로직 재확인 (STATIZ 계약/팀이동 이력으로 전부 교차 검증됨)
v1에서 수동으로 "이미 KBO 경력이 있어 재영입/이적"으로 판단해 제외했던 사례들이, STATIZ의 "계약/팀이동" 이력과 전부 일치함을 확인했다: 조쉬 린드블럼(롯데→두산), 트레비스 밴와트(SK→kt), 에스밀 로저스(한화→넥센), 닉 킹엄(SK→한화), 라울 알칸타라(kt→두산→키움), 에릭 요키시(넥센/키움→NC), 아리엘 후라도(키움→삼성), 로건 앨런(NC→kt, 2026년 이적이라 이번 범위 밖). 웨스 파슨스(NC)는 v1에서 "위키 원문 오류 가능성"으로만 표시했던 것이, STATIZ로 활약연도 2021-2022 전부 NC임이 확인되어 오류였음이 최종 확정됐다.

## 174명 추정치와의 비교

최종 167명. 애초 추정치(174명, 재검증 필요 명시)와 7명 차이. 이번 조사는 위키백과/나무위키 팀 문서 기반 재구축 + STATIZ 전수 대조라는 이중 검증을 거쳤고, 실제 발견된 오류들(중복 집계, 연도 오기, 투수 아닌 선수 혼입 등)을 감안하면 167명이 174명보다 더 근거가 탄탄한 숫자라고 판단한다. 다만 아래 "조사 한계"에 적은 대로 완전한 보장은 못 한다.

## 조사 한계

- 위키백과/나무위키가 최신화되지 않은 최근 시즌 일부(KIA 2022~, 한화 2020~, 롯데 2025)는 "틀:○○년 KBO 리그 외국인 선수" 문서와 뉴스로 보완했다. 이 구간은 상대적으로 신뢰도가 낮았으나, STATIZ로 전수 재검증했으므로 최종본은 안전하다.
- "계약했으나 개막 전 방출되어 STATIZ 페이지 자체가 없는" 선수가 여전히 누락되어 있을 가능성은 배제할 수 없다(위키 문서 자체가 이런 선수를 안 실었을 수 있음). 마이크 로리(kt, 2014)는 이런 사례로 확인됐지만(0경기, 페이지 없음 확정) 모집단에서 제외 상태를 유지했다 — 계약 자체가 매우 이른 시점(1군 진입도 전)이라 실질적으로 다른 사례들과 성격이 다르다고 판단했기 때문이다.
- STATIZ 검색은 선수 등록명이 성(姓)이 아니라 이름으로 되어 있는 경우가 많아(예: 오스틴 보스→"보스", 딜런 파일→"딜런", 코너 시볼드→"코너"), 정확한 대조를 위해 다양한 검색어를 시도했다. 일부는 동명이인과 혼동될 여지가 있었으나 생년월일·소속팀으로 모두 구분했다.
