# KBO 외국인 투수 성과 예측 / 스카우팅 분석

프로야구단 전력분석/외국인 선수 스카우트 직무 지원을 위한 포트폴리오 프로젝트다.

## 핵심 질문

KBO 입성 이전 MLB/MiLB 성적과 선수 특성으로 신규 외국인 투수의 KBO 첫 시즌 성과(주 타깃: STATIZ WAR)를 예측할 수 있는가?

자세한 프로젝트 배경, 분석 단위, 데이터 소스, 방법론 원칙은 [PROJECT_GUIDELINES.md](PROJECT_GUIDELINES.md)를 참고한다.

## 현재 상태

Phase 1: Feasibility Test 진행 중 — 데이터 확보 가능성 검증 단계.

## 데이터 출처

* MLB/MiLB 원자료: [MLB Stats API](https://statsapi.mlb.com)
* KBO 첫 시즌 성과: [STATIZ](http://www.statiz.co.kr)

원본 스크래핑 데이터는 이 저장소에 포함하지 않는다. 자세한 내용은 PROJECT_GUIDELINES.md의 데이터 공개 원칙을 참고한다.
